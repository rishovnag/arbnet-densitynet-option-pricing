# Datasets

This document specifies the data required to reproduce the paper. The package can also be exercised end-to-end on **synthetic surfaces** (generated by `SyntheticSurfaceGenerator` and `RoughBergomiGenerator` in `arbnet/data/synthetic.py`) with no external downloads, but real-world results require the data described below.

---

## 1. Primary: NSE Nifty 50 options (required)

**What:** Daily settlement prices, open interest, and volume for Nifty 50 index options (weekly and monthly expiries).

**Source:** National Stock Exchange of India — F&O Bhavcopy.

- URL: <https://www.nseindia.com/all-reports>
- Path: All Reports → Derivatives → Derivatives Daily Reports → "F&O – UDiFF Common Bhavcopy Final" (or legacy "FO_*.csv").
- Format: CSV, one file per trading day.
- Cost: free.

**Coverage requested:** 2019-01-01 through 2024-12-31 (≈1500 trading days). The paper's experimental design assumes ≥3 years of clean daily snapshots covering at least one volatility regime change (e.g. COVID Mar 2020 and post-2022 RBI tightening cycle).

**Fields used (legacy schema):**

| Column      | Purpose                                  |
|-------------|------------------------------------------|
| `SYMBOL`    | filter to `NIFTY`                        |
| `INSTRUMENT`| filter to `OPTIDX`                       |
| `EXPIRY_DT` | option expiry                            |
| `STRIKE_PR` | strike                                   |
| `OPTION_TYP`| `CE` (call) or `PE` (put)                |
| `SETTLE_PR` | daily settlement (preferred over CLOSE)  |
| `OPEN_INT`  | open interest (for liquidity filtering)  |
| `TIMESTAMP` | snapshot date                            |

The loader `arbnet.data.loaders.load_nse_options_csv` autodetects legacy vs. new (UDiFF) schemas.

**Caveat:** deep-OTM weekly options on NSE often have stale settles after volatility spikes, particularly more than ~3% OTM and more than 14 DTE. The default `FilterConfig` drops contracts with `SETTLE_PR < 0.05` (essentially zero), `|log(K/F)| > 0.5`, or that violate no-arbitrage bounds.

## 2. Underlying: Nifty 50 spot index (required)

**What:** Daily closing level of the Nifty 50 index.

**Sources (any one):**

1. **Yahoo Finance** — ticker `^NSEI`, accessible via `yfinance`:
   ```python
   import yfinance as yf
   nifty = yf.download("^NSEI", start="2019-01-01", end="2025-01-01")
   ```
2. **NSE historical data** — <https://www.nseindia.com/reports-indices-historical-index-data>.
3. **NSEpy** (community library): `pip install nsepy`.

The package's loader infers spot from put-call parity at the nearest expiry if not supplied, but matching the exchange's official close is strongly preferred.

---

## 3. Risk-free rate (required)

**What:** Short-end risk-free rate to discount option payoffs. We use the **91-day Treasury bill yield** as published by the Reserve Bank of India.

**Source:**
- RBI Database on Indian Economy — <https://dbie.rbi.org.in> → "Weekly Statistical Supplement" → "Treasury Bills (Cut-off Yield)".
- Direct CSV: <https://www.rbi.org.in/Scripts/PublicationsView.aspx?id=22158> (weekly schedule).

Defaults baked into `OptionsSnapshot` (`risk_free_rate=0.065`) are typical 2023–2024 levels. For production, supply a date-matched series.

**Alternatives:** MIBOR (Mumbai Interbank Offered Rate) for very short tenors; reported by FBIL at <https://www.fbil.org.in>.

---

## 4. Dividend yield (required, low-impact)

**What:** Nifty 50 trailing twelve-month dividend yield.

**Source:** NSE indices factsheet — <https://www.niftyindices.com/indices/equity/broad-based-indices/nifty-50>.

A monthly snapshot is sufficient. Default `dividend_yield=0.012` is a reasonable 2023–2024 average. Sensitivity to this parameter is modest (< 30 bps in IV).

---

## 5. Implied volatility (derived)

**What:** Per-contract Black-Scholes implied volatility.

**How produced:** Inverted from market settle prices using `arbnet.data.iv.implied_vol_newton`, a vectorized Newton inverter with intrinsic-value and upper-bound guards.

No external download needed.

---

## 6. Auxiliary context features (optional, recommended)

These can be passed as a `context` dict to `build_features` and concatenated as inputs to ArbNet's envelope, ICNN, and monotone modules.

| Feature        | Source                                                                  | Notes                                        |
|----------------|-------------------------------------------------------------------------|----------------------------------------------|
| India VIX      | NSE — <https://www.niftyindices.com/indices/equity/strategy-indices/india-vix> | 30-day forward IV; daily close.       |
| 1-week realized vol of Nifty | computed from spot closes                                   | useful for regime context.                   |
| Bank Nifty IV  | NSE Bank Nifty options                                                 | cross-sectional vol of vol surrogate.        |
| USD/INR        | RBI reference rate                                                     | macroeconomic context.                       |
| FII/DII flows  | NSE daily reports                                                      | liquidity / sentiment.                       |

---

## 7. Event calendar (optional, for regime analysis)

For the regime-robustness experiments, a calendar of high-impact events:

- **RBI MPC dates** — <https://www.rbi.org.in/Scripts/BS_PressReleaseDisplay.aspx>.
- **Union Budget dates** — annually announced; usually 1 February.
- **Quarterly results week markers** — derived from constituent companies' announcement calendars.
- **Major macroeconomic releases** — CPI/WPI/IIP/GDP.

A simple CSV with columns `(date, event_type, severity)` suffices.

Reviewers may request validation on a non-Indian benchmark. Options:

1. **CBOE DataShop** — <https://datashop.cboe.com> — paid, daily settlement available.

Not required for the main paper; supplementary only.

## 9. Synthetic fallback (no downloads required)

For pipeline development and smoke tests, the package ships two generators:

- `SyntheticSurfaceGenerator` (fast, SSVI-parametric): arbitrage-free by construction; produces a snapshot in ~10 ms.
- `RoughBergomiGenerator` (slow, Monte Carlo): realistic short-dated smile shape; produces a snapshot in ~10 s with 4000 paths.

```python
from arbnet.data import RoughBergomiGenerator
gen = RoughBergomiGenerator(H=0.07, eta=1.9, rho=-0.7, xi0=0.04)
snap = gen.generate(n_strikes=21, maturities_days=[7, 14, 30, 60, 90])
```

These also serve as the *ground-truth* generator for hedging-PnL simulations: we train pricers on one DGP, then evaluate hedging on rough-Bergomi-simulated paths to test out-of-distribution robustness.

## Suggested directory layout

```
data/
├── nse/
│   ├── fo_bhavcopy/         # daily CSV downloads, one per trading day
│   └── nifty50_spot.csv     # daily index closes
├── rates/
│   └── 91d_tbill.csv        # daily risk-free
├── events/
│   └── india_macro_calendar.csv
└── auxiliary/
    ├── india_vix.csv
    └── usdinr.csv
```

A helper script `scripts/prepare_data.py` to fetch and normalize these into a single Parquet dataset is left as future work; the package today expects per-day CSVs at a configurable path.
